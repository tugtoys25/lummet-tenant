Postback Hub

Everything about getting conversions back from your affiliate programs, in one place: connect a program, watch what arrives, test it, and send it on. Secrets are generated and stored encrypted by this site, so nothing has to be set up outside this dashboard.

ⓘ How to use this tab: Overview

This is the health page for all your postbacks. A postback is the message an affiliate program sends to this site when a player you referred registers, deposits or is paid for.

  1. Read the five cards: active integrations, postbacks accepted in the last 24 hours, conversions that could not be matched to a click, rejected postbacks, and when the last one was accepted.
  2. Read Needs attention. Each line says what is wrong in plain words and links to the tab that fixes it.
  3. Follow Getting started from top to bottom. A tick means that step is done.

What next: If you have no integration yet, open Connect a program. If one has never received a postback, open Integrations, then Setup links and make sure the URLs are pasted into the program.

Getting started

    ⓘ How to use this tab: Connect a program, using what you have

    Use this when the affiliate program and your account already exist in this dashboard. It adds the postback integration to them and gives you the URLs to paste into the program.

    1. Step 1. Pick the affiliate program, then your account in it. The line under the boxes shows what already uses this program.
    2. Step 2. Choose the program type (for example Pin-Up). This decides which macros and click-ID name are used. Give the integration a name you will recognise later.
    3. Step 3 (optional). Tick the casinos that send players through this program. Search, or tick a domain group to select its casinos. Casinos that already have a tracking link keep it.
    4. Press Create integration and show setup. A box appears at the top with the finished URLs. Copy each one into the matching postback field in the affiliate program.
    5. In the same box, tick the tracking links that should carry the click ID and press Apply.

    What next: Go to Test and run a live test, then watch Activity for the first real postback.

    Related pages: Affiliate Programs · Affiliate Accounts · Tracking Links · Casinos

    ⓘ How to use this tab: Connect a program, setting up something new

    Use this when the program is not in this dashboard yet. One form creates the partner, the program and your account, then the integration. Nothing that already exists is duplicated or renamed.

    1. Step 1. Choose the partner (the company) or pick "+ New partner" and type its name. Then type the program name and a name for your account. The affiliate dashboard address and your ID in that program are optional.
    2. Step 2. Choose the program type. It fills in sensible names for you, which you can change. Name the integration.
    3. Step 3 (optional). Tick the casinos that go through this program.
    4. Press Create integration and show setup, then paste the finished URLs into the program.

    What next: Test it in Test, then watch Activity. Later you can add commission rates on the Commercial Terms page.

    ⓘ How to use this tab: Integrations

    Every postback integration you have, one row each. An integration is the address and secret this site gives a program so it can report conversions.

    1. Setup links shows the finished URLs for that integration, with its secret already inside. Paste them into the program.
    2. Test jumps to the Test tab with this integration selected.
    3. More holds the rarer actions: copy the bare address, show or replace the secret, rotate the address, or archive the integration.
    4. The Last 24 h and Health columns show whether postbacks are arriving and being matched to clicks.

    What next: If a row shows "no data yet", the program has not called it. Open Setup links and check the URLs are saved in the program. Archive integrations you no longer use; archiving only turns them off.

    ⓘ How to use this tab: Test

    Checks that an integration works before you trust it with real money.

    1. Choose the integration.
    2. Run Test pretends a conversion arrived and walks it through click matching, commission terms and commission calculation. It records nothing.
    3. Live test (real auth) signs a request with the real secret of that integration and runs it through the real authentication, also without saving a conversion. Use it to prove the secret works.
    4. Read the checklist: a tick means that step passed, a cross says what to fix.

    What next: When both tests pass, put the URLs in the program and watch Activity for a real postback.

      ⓘ How to use this tab: Forwarding
        
      
          
      Sends every conversion this site receives on to another system, so your tracker or ad platform learns what converts.
      
          
      1. Under Send to choose a tracker or any URL, Meta Conversions API or TikTok Events API, and give the rule a name.
      2. For a tracker, pick a starting template, then check the address. Words in braces are replaced with real values for each conversion.
      3. For Meta or TikTok, enter the pixel and access token (stored encrypted) and use the test event code first.
      4. Choose which events and which statuses to forward, then save. Each conversion is sent once per status.
      5. Failed deliveries appear under Recent deliveries and can be retried.

      ⓘ How to use this tab: Activity
        
      
          
      A log of every postback the programs have sent, accepted or not. It is the quickest way to see why something did not count.
      
          
      1. Read the Outcome of each line.
      2. accepted: recorded as a new conversion. updated: an existing conversion changed status. duplicate: already recorded, ignored.
      3. unattributed: it arrived but could not be matched to a click. Usually the click-ID name on your tracking link does not match what the program sends back.
      4. rejected: refused before recording, most often a wrong or missing secret. The details column says why.
      5. Use the filter to show one outcome, and Refresh to reload.
      
          
      What next: Fix the cause shown in Details, then send another test and refresh.

      ⓘ How to use this tab: Advanced
        
      
          
      A manual form for integrations that the guided Connect tab does not cover. Most users never need it.
      
          
      1. Use it when a provider signs requests (HMAC or signed query), needs an IP allow-list or replay protection, or sends unusual field names.
      2. Choose the affiliate account, name the integration and pick the authentication method.
      3. Leave "Existing Worker secret name" empty so this site generates and stores the secret.
      4. Only fill in the field mapping when the defaults do not understand the parameter names of the provider.
      
          
      What next: After creating it, open Integrations, then Setup links or More, then Show secret to get what to paste into the program.
