News Inline Advertisements

Manage advertisements injected into news article bodies. Ads come from two sources:

  • Ad Components — Create components with type ad in the Components page. Each active ad component is automatically injected. This is the recommended way to manage multiple ads.
  • Fallback HTML — If you don't want to use components, paste raw HTML below. This is injected as a single ad.

Placement control: Type <!--AD-->, <!--AD1-->, <!--AD2-->, etc. anywhere in a news article's content to control exactly where each ad appears. If no markers exist, ads are auto-inserted after the 3rd, 6th, and 9th paragraphs.

Raw HTML used when no ad components exist. Leave empty to rely entirely on ad components. If you type component:your-slug here, that specific component will be loaded as the fallback ad.
